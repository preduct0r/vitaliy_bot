# Тестовый Telegram-интерфейс гипотез

Режим выключен по умолчанию. Для отдельного тестового бота и его отдельного
каталога состояния задаются `VITALY_BOT_HYPOTHESES_DEVELOPMENT=1`,
`VITALY_BOT_HYPOTHESES_CORPUS_DIR`, `VITALY_BOT_HYPOTHESES_ORIGINAL_DIR`,
`VITALY_BOT_HYPOTHESES_ADJUDICATION_DIR` и
`VITALY_BOT_HYPOTHESES_MANIFEST_SHA256`. Каталоги и база доверенных запросов
должны находиться вне Git. Сервис использует общий runner и существующий FIFO;
эта конфигурация не создаёт отдельный poller. Проверка корпуса выполняется при
постановке и исполнении каждой задачи.

Исторический корпус — материал разработки, а не независимая контрольная
выборка. Синтетические проверки не являются разрешением на выпуск. Тестовую
сессию с отдельным токеном выполняет управляющий агент после s4c.

Отзыв хранится отдельно от материалов кейса. Очередь 04:00 оценивает текст
частным проходом и независимо проверяет соответствие закрытому каталогу
общих правил. В генерацию кандидата поступают лишь безопасные шаблоны; перед
публикацией применяются существующие проверки кандидата и регрессий. Новые
запуски получают только утверждённые общие правила своего пакета; текст
чужого отзыва и ссылки на его исходный кейс в запрос не включаются. Отметки
без объяснения сами по себе не доказывают общее методическое правило.
